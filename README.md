Запуск:
Напишите в консоли: npm install
Нажмите enter.

Затем напишите: npm run dev

И откройте в браузере адрес: http://localhost:3000.

Шаг 6. Использование
Нажмите «Загрузить видео» и выберите горизонтальный видеофайл (MP4, MOV, AVI, WebM).

Дождитесь загрузки — появятся метаданные файла.

Выберите способ кадрирования: центр, размытие фона или ручной выбор.

Укажите начало и конец фрагмента, разрешение и качество.

Нажмите «Обработать видео».

Дождитесь завершения — появится кнопка скачивания.
